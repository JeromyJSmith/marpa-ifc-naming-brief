## What Is Not Happening Yet

The current phase does not migrate live Pixeltable data.

The current phase does not rewrite Vectorworks files.

The current phase does not collapse all lanes into one app.

The current phase does not treat open-source projects as blindly copied code. It uses local source intelligence, licenses, and adapter boundaries to decide how each source is used.

## Stakeholder Decision Point

The stakeholder decision is whether the model makes sense:

- one governed platform;
- six coordinated lanes;
- source evidence first;
- traceability before automation;
- client-facing and technical surfaces working together;
- financial intelligence grounded in project data.

If that model is accepted, the next work is specification completion and implementation sequencing.
