Project coordinates

Without georeferencing, the project loses its real-world position

A project origin, Cartesian coordinate system, and site georeference are not just survey details. They are what let design geometry line up with real space, other exports, maps, measurements, and future projects.

Design value

Location makes the model useful before estimating even starts

Seasonal shadow studies

With true project location, north, date, and time, Vectorworks can simulate sunlight and shadows across seasons. That helps MARPA see shade, heat, comfort, plant performance, view impacts, and solar exposure while the design is still moving.

3D planting decisions

If trees and plants become 3D objects, they can cast shadows, show mature canopy, reveal spatial conflicts, and connect plant identity to cost, risk, maintenance, and site performance.

Project liability context

If the project does not know where it is on earth, it cannot reliably know its wildfire area, municipal rules, setbacks, slope behavior, climate exposure, or site-specific design constraints.

Colorado wildfire context

Georeferencing turns code changes into spatial design checks

The July 1, 2026 shift matters because Colorado jurisdictions are implementing wildfire-resiliency requirements around WUI mapping, defensible space, structure hardening, and local plant restrictions. A project needs location before the system can know which rules apply.

Find the jurisdiction and wildfire area

Latitude, longitude, parcel, address, and project boundary determine whether the site sits inside a mapped wildfire area and which local code language applies.

Create structure ignition zones

Generate 0-5 ft, 5-30 ft, and 30-100 ft zones around buildings, decks, stairs, attachments, detached structures, fences, and retaining walls.

Check plants, materials, and distances

Flag combustible mulch, trees, shrubs, juniper, arborvitae, Gambel oak, fences, retaining walls, firewood, and other materials when local rules make location or distance important.

Show the issue in the model

Highlight the object, show the distance, name the source rule, and let the designer adjust the layout while preserving the design intent.

What the pipeline can flag

These checks only work when the project has coordinates and 3D objects

0-5 ft immediate zone

Noncombustible hard surface materials, no new trees, plantings and combustible mulch checked against the building perimeter.

5-30 ft intermediate zone

Tree crowns, shrub groups, dead material, combustible accumulations, firewood, and species restrictions checked by distance.

30-100 ft extended zone

Tree spacing, slope, canopy continuity, and fuel behavior reviewed against site conditions.

Research notes

Why this matters now

Finding Why georeferencing helps
Vectorworks solar studies use location, date, time, and north orientation to show sunlight and shadows. The project needs true position and orientation for reliable seasonal shadow simulation.
Colorado wildfire guidance organizes defensible space around structures into 0-5 ft, 5-30 ft, and 30-100 ft zones. Those zones are geometry problems: draw buffers around structures, then test objects and materials inside them.
Jefferson County's Wildfire Resiliency Code is effective July 1, 2026 for permits on or after that date, and includes specific site requirements. The system can map a project to jurisdiction, date, WUI area, and applicable local code language.
Local jurisdictions can name prohibited or discouraged plants. Jefferson County lists juniper species, arborvitae, and Gambel oak; Louisville prohibits new juniper plantings; Boulder recommends removing junipers. Plant objects need botanical identity and location so the model can show possible conflicts before plans are finalized.
