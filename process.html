Process

The sequence is what makes the data reliable

We first learn what is actually inside each project file and export. Then we name the objects. Then we create the downstream data products.

inventory actual project files
↓
export every useful representation
↓
extract text, geometry, images, tables, quantities
↓
compare coverage across formats
↓
build the naming bridge from real evidence
↓
load, analyze, enrich, and write forward

What this prevents

  • Guessing table schemas before the source data is known.
  • Losing original Vectorworks naming and context.
  • Assuming IFC contains geometry or quantities that may only exist in DWG, PDF, or worksheets.
  • Building cost analysis on disconnected spreadsheet rows.
  • Creating 3D enrichment without source lineage.
