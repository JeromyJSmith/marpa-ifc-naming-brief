Pipeline map

From one design state to connected BIM and cost evidence

The first job is to preserve the design state, export every useful representation, compare what each export contains, and only then create the MARPA naming and classification package.

1. Same project / same design stateOpen the current Vectorworks project file and keep the export run tied to that state.
2. Export every useful formatVWX metadata, PDFs, DWG/DXF, IFC versions, worksheets, schedules, resource assets, sheet images, and design-layer images.
3. Parse into evidence packagesSeparate text, vector paths, images, tables, geometry, quantities, symbols, records, and source receipts.
4. Compare coverageFind what each format contains and misses: object names, layer context, XY, Z, quantities, materials, plant data, costs, and IFC properties.
5. Build MARPA naming bridgeAssign stable MARPA object identity while preserving the original Vectorworks naming and source artifact references.
6. Attach downstream meaningMap to IFC entities, property sets, quantities, cost categories, and 3D enrichment targets.
7. Review and write forwardUse the resulting package for estimating, dashboards, 3D review, IFC validation, and later Vectorworks writeback.
